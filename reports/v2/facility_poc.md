# Facility PoC — 엘리베이터 칸-문 × 칸별 혼잡도 (4호선)

- 빠른하차정보(공공데이터포털, 기준일 20241231): 2357행, 4호선 277행·엘리베이터 53행·26개 역
- 같은 엘리베이터의 양방향 표기(1~7호선) 72곳 중 67곳이 '칸 번호 합 = 칸 수 + 1' (4호선 9/9) → 빠른하차정보의 칸 번호는 진행 방향 기준
- 칸별 혼잡도 샘플의 칸 번호 기준은 공식 정의 없음 → 반대 기준 가정 결과를 함께 보고

| 항목 | 값 |
|---|---|
| 매칭 조합 (엘리베이터 역 도착 역간 × 30분, 열차 평균 60%+) | 129 (역간 27) |
| 옆 칸이 5%p 이상 덜 붐빈 비율 | 40% |
| 그때 감소 (평균 / 중앙) | 10.8 / 8.8%p, 한 칸 더 걷기 |
| 후보 칸이 모두 100% 이상 | 31건 (출발 시각 대안 권유) |
| 칸 번호 기준을 반대로 가정해도 같은 칸 | 51% |

예시: 동대문→동대문역사문화공원 (충무로 방면) 평일 07:30, 통과 6회 평균
- 엘리베이터 7-1 → 가장 가까운 칸 7번째 (121.5%)
- 후보 {6: 119.0, 7: 121.5, 8: 111.4} → 8번째 칸 (111.4%, −10.1%p, 1칸 더)
- 칸 번호 기준을 반대로 가정해도 8번째 칸 (−9.6%p)
- 후보 칸이 모두 100% 이상: True → 출발 시각 대안을 함께 권함

한계: 4호선 샘플(편성 6개, 2026년 6월 평일)의 과거 패턴이며 실시간이 아니다. 통과 수가 적은 조합이 있다.
