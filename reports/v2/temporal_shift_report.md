# v2.2 Time Shift 리포트 (temporal_shift_mart)

- 실행: `python scripts/v2/22_build_temporal_shift_mart.py --n-random 150 --seed 42`
- 표본: Tier C 20쌍 + 무작위 150쌍 × weekday 기준 출발 07:30, 08:00, 08:30, 17:30, 18:00, 18:30 = 1,020건, 후보 행 6,362개
