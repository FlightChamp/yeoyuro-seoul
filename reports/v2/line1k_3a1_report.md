- [미확인] 조정 전후 정차 횟수(+15회) 자체는 조정 전 시각표가 없어 대조 못 함.

### 1.4 `00:00:00` = 무정차 통과 [공식 정의 미확인 · 기록으로 확인]
- 공공데이터포털 15098251 설명(미러 기준)에는 주중주말·방향·급행여부(1/0) 정의만 있고 `00:00:00` 언급 없음.
- 열차별 기록 검증(빌드 §3):
  1. 7,071행 모두 급행, 일반열차 0행
  2. 그 행의 출발 칸은 전부 실제 시각(비거나 00:00:00 인 경우 0)
  3. 급행 675개를 출발 칸 시각순으로 놓으면 연속 역쌍이 일반열차의 실제 인접 역쌍과 모두 같음 (예외 = 3A-0 의 이상 3편성)
  4. 경인 급행이 공식 정차역인 대방·신길·개봉에서는 0, 비정차로 알려진 구일·오류동·온수에서만 나타남
- 판단: 그 역을 지나가는 시각을 출발 칸에 적은 **통과 행**. 정차·승하차로 쓰지 않는다.
- 음수 정차시간 차단: 통과 행은 도착을 비우고 mart 에서 제외, 남은 행에서 음수가 나오면 빌드가 멈춘다(테스트 `test_negative_dwell_rejected`). 급행은 3A-1 mart 에 없음.

## 2. ① 다음 열차 대기 — 목적지 정차 필터 설계

### 2.1 규칙 (구현: `NextTrainIndex`)
- 후보 열차 = 같은 열차 안에서 **출발역 다음 순서에 목적지(또는 다음 환승역)가 정차역으로 있는** 열차.
- 대기 = 후보 열차의 출발역 출발 − 질의(도착) 시각. 탑승시간 = 목적지 도착 − 출발역 출발.
- 이 한 규칙으로 자동 제외되는 것:

| 경우 | 예 | 처리 |
|---|---|---|
| 중간 종착 | 석계→월계인데 앞 열차가 광운대 종착 | 건너뛰고 월계까지 가는 열차 (테스트 고정) |
| 다른 분기 | 구로에서 구일(경인) 가는데 앞 열차가 가산(경부)행 | 건너뜀. 구일→가산 직행은 없음 |
| 지선 셔틀 | 광명행 | 영등포~금천구청 안에서만 후보 |
| 직통 | 남영→시청 | 서울역에서 갈아타지 않는 한 열차 |
| 급행 통과역 | (3A-3) 통과 행은 정차역이 아니므로 후보 불가 | |
| 막차 뒤 | | None → 경로 없음 |

### 2.2 3A-2 에서 정할 것
- **같은 1호선 안 갈아타기**: 구일→가산처럼 직행이 없으면 구로에서 다른 1호선 열차로 갈아타야 함.
  - 그래프에 '1호선 → 1호선, 같은 역' 갈아타기를 두고, 도보 0분(같은 승강장 여부는 [미확인] — 구로는 경인·경부가 다른 승강장일 수 있음) + 시각표 대기.
  - 빌드 §4 의 '한 열차 기준' 대기와 '구로 갈아타기' 중 빠른 쪽을 엔진이 고름.
- **목적지 = 구간 끝**: 경로 탐색에서 필터의 '목적지'는 최종 목적지가 아니라 그 열차에서 내릴 역(다음 환승역).

## 3. ② 기존 1~8호선(배차÷2) 대비 대기시간 급변 처리 기준

### 3.1 무엇이 다른가
- 1~8호선·9호선 환승 대기 = 그 시각 배차 ÷ 2, 최대 12분(D-044). 최초 승차 대기는 기본 미포함(D-003·D-050). 분 단위 실제 대기는 쓰지 않는 **기대값 체계**.
- 코레일 구간은 열차마다 행선지가 달라, 배차÷2 는 '목적지에 가는 열차' 기준 대기를 과소추정할 수 있음.

### 3.2 측정 (빌드 §4, 평일, D-086 기준을 계산 전에 고정)
- 급변 셀(E − H ≥ 3분 또는 E/H ≥ 2): 전체 19.2%, 출퇴근 14.9%. 계통별 경부가 가장 높음(출퇴근 25.7%).
- 원인 분해: 목적지 필터만으로 ≥ 3분 12.3% vs 배차 불규칙만으로 ≥ 3분 1.7% → **급변은 주로 '목적지에 안 가는 열차' 때문.**
- 대표 사례: 회기·외대앞·신이문·석계 → 가산디지털단지·독산·금천구청 (출퇴근 E 약 7.3분 vs H 약 2.5분). 경원선 열차 대부분이 구로에서 경인선으로 가기 때문. 구로 갈아타기를 넣으면 줄어들 수 있음(3A-2).
- 인접 30분 사이 기대 대기 차이 ≥ 3분: 16.6%.

### 3.3 처리 기준 (D-086 초안, 3A-2 에서 확정)

| # | 기준 | 이유 |
|---|---|---|
| R1 | 분석·점수에는 코레일 구간만 **30분 bin 기대 대기(목적지 필터)** 사용. 1~8호선·9호선은 기존 규칙 그대로 | 기대값 체계 유지(D-044) + 기존 결과 보존 |
| R2 | 분 단위 실제 다음 열차는 화면 보조 정보. 기대값과 5분 이상 차이 나면 "다음 열차까지 n분 — 평소보다 깁니다" 안내 | 1분 늦게 출발해 대기가 한 배차만큼 뛰는 톱니 모양을 판정에 넣지 않음. 5분 = T1 소요 증가 허용치 |
| R3 | 목적지행 열차까지 60분 초과 또는 막차 뒤 → 대기로 메우지 않고 '운행 없음', 후보 제외 | 드문 열차를 긴 대기로 계산하면 존재하지 않는 경로가 생김 |
| R4 | 최초 승차 대기 미포함 유지(D-003). 코레일 갈아타기(타 노선→코레일, 1호선→1호선)에만 시각표 기대 대기 | 1~8호선과 같은 정의 |
| R5 | 12분 상한은 코레일 기대 대기에 적용하지 않음(시각표 실측). 민감도로 상한 12분 적용 결과 같이 보고 | 상한은 배차 추정값용 |
| R6 | bin 경계 급변은 보정하지 않음(시각표 사실). 3A-2 변경 보고에서 '시각표 대기' 원인으로 분류 | 원인 추적 가능성 |
| R7 | 민감도: 코레일 구간 대기를 (a) 목적지 필터 기대 대기 (b) 전체 열차 배차÷2 로 각각 계산해 유형 변화율 보고 | 정책 선택이 결론을 바꾸는지 확인 |
