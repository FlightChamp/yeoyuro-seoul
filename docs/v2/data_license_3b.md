## 3. 사용자가 확인할 것 (결과를 알려 주면 D-107 로 공개 범위를 정한다)

1. 경의중앙선·수인분당선 시각표 xlsx 를 받은 **코레일 게시물 화면**: 게시물 URL, 게시물 하단의 공공누리 마크 유형(제1~4유형) 또는 '저작권' 문구 — 화면 갈무리
2. 공항철도 누리집(www.arex.or.kr 또는 www.airportrailroad.com) 하단 **'저작권 정책'** 또는 이용약관 화면, 시각표 게시물의 공공누리 마크
3. 1·2 에 표시가 없으면: 코레일 공공데이터 담당(누리집 '공공데이터 제공 신청', 공공데이터법 제27조) 또는 국민신문고로 "광역전철 열차시각표를 가공(열차별 정차표)해 비상업 공개 서비스·공개 저장소에 재배포해도 되는지" 질의

## 5. 공항철도 최신성은 따로 관리

재배포 허용 여부와 시각표 최신성은 별개다. 공항철도 2025-12-29 파일은 2026-10-23 개정(직통 증회) 뒤 일반열차 시각과의 대조 전까지 '참고 경로' 를 유지한다(D-105 2절). 최신 일반열차 시각표 확보 경로:
- 공항철도 누리집 시각표 게시물 — 2026-10-23 증회 보도(위키트리)에 '변경된 직통열차와 **일반열차** 운행시각표는 역사 게시 안내문이나 공식 누리집(www.arex.or.kr)에서 확인' 이라고 되어 있다. **일반열차 시각도 바뀌었을 수 있다는 신호**이므로 참고 경로 유지가 맞다. 개정 시각표 파일은 미확인 — 사용자가 누리집에서 내려받아 주면 52 로 대조
- 국가철도공단 열차별운행시각표 API(R1) — 공항철도 포함 여부·이용허락 미확인
