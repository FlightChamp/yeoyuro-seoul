# 시간 진행형 경로 평가 (Time-dependent route evaluation)

v2.0 의 결론: **v1 의 출발 bin 고정은 경로 순위(최속 경로)는 거의 바꾸지 않지만, 혼잡 지표는 크게 바꾼다.**
같은 경로를 다시 계산했을 때 40분 이상 이동의 최대 기대혼잡은 평균 10.06%p, exposure_100 은 평균 2.82분 달라졌다.
수치 출처: [`reports/v2/td_engine_validation.md`](../../reports/v2/td_engine_validation.md)
(평일 5개 출발시각 × Tier C 20쌍 + 무작위 150쌍 = 850건, seed 42).

## 1. v1 한계

`RouteScorer.__init__` 가 `time_bin` 을 한 번 정하고, 모든 edge 혼잡도와
환승 대기(`apply_transfer_wait(..., scorer.time_bin)`)에 같은 bin 을 쓴다.
08:20 에 출발해 50분 이동해도 마지막 구간까지 08:00~08:30 혼잡을 적용한다.

## 2. v2 방식

```
t_i = t_dep + w_0 + Σ_{j<i} (주행 d_j + 정차 s_j + 환승도보 a_j + 환승대기 h_j)
```

| 항목 | v1 | v2 |
|---|---|---|
| edge 혼잡 | 출발 bin | edge 진입 시각 bin (경계를 넘으면 분할) |
| 환승 대기 | 출발 bin 배차/2 | 환승역 도착 시각 bin 배차/2 |
| 이벤트 배수 | 출발 시각의 hour | edge 진입 시각의 hour |
| 정차시간 | 총합으로 1회 가산 | 해당 역에서 시간축에 삽입 (차내 시간으로 노출 집계) |
| 최초 승차 대기 | 미반영 | 옵션 (기본 미반영, D-003) |

구현: `yeoyuro_v2/time_dependent.py` — `TimeDependentEvaluator`(경로 1개 평가), `TDRouter`(OD 후보 생성 + 평가).
v1 코드는 수정하지 않는다(D-001).

## 3. time-bin 조회 정책 (D-002)

| 정책 | 정의 | 용도 |
|---|---|---|
| step | bin 안 상수, edge 구간이 경계를 넘으면 bin 별로 분할 적분 | **기본값** |
| floor | edge 진입 시각 bin 하나 | 비교 |
| linear | bin 중심 사이 선형 보간 (edge 중점) | sensitivity 전용 |
| fixed | 출발 bin 고정 | v1 재현·회귀 테스트 |

검증 결과 step 과 floor 는 사실상 같다 (exposure_100 평균 절대차 0.05분, Route Shift 판정 일치 99.8%).
edge 가 평균 2분 내외로 짧아 경계 분할 효과가 작기 때문이다. linear 는 판정 일치 96.7% 로
조금 더 다르므로 v2.3 sensitivity 축에 포함한다.

## 4. 후보 생성 (D-010)

Yen 은 정적 가중치에서만 돈다. 출발 bin 과 이동 중 통과하는 bin 각각의 가중치로 Yen(K=5)을 돌려 합집합한 뒤
전부 시간 진행형으로 재평가한다. 검증: 쾌적 최선 경로가 단일 bin K5 와 99.2%, 다중 bin K10 과 96.2% 일치.
K10 불일치 3.8% 는 v2.3 배치에서 K 를 올릴지 판단할 근거로 남긴다.

## 5. 검증 결과 요약

| 항목 | 결과 | 판정 |

| B. 같은 경로의 지표 차이 (<20분 / 20~40분 / 40분+) | 최대혼잡 평균 0.52 / 5.86 / 10.06 %p, exposure_100 평균 0.13 / 0.90 / 2.82 분 | 이동이 길수록 v1 편향 큼 |

## 6. 대표 사례 (detail csv 에서 발췌)

| OD · 출발 | 소요 | 최대혼잡 v1 → v2 | exposure_100 v1 → v2 | Route Shift v1 → v2 |
|---|---|---|---|---|
| 노원 → 양천구청 · 17:40 | 63.0분 | 75.6 → 111.5 | 0.0 → 16.0분 | 실패 → 성공 |
| 까치산 → 중화 · 18:15 | 63.2분 | 136.8 → 90.7 | 8.2 → 0.0분 | 성공 → 실패 |

노원 → 양천구청은 17:40 bin 으로만 보면 혼잡하지 않은 이동이지만, 실제로 후반 구간에 진입하는 18시 이후에는
100% 이상 구간을 16분 지난다. v1 은 이 퇴근 피크 진입을 보지 못했다. 반대로 까치산 → 중화는 v1 이
출발 bin 의 고혼잡을 후반 구간까지 끌고 가 과대평가했다.

## 7. 해석과 한계

- 이 표본은 **평일 피크 부근 5개 시각, 균등 무작위 OD** 다. 수요 가중이 아니며 도시 전체 비율로 일반화하지 않는다.
- Route Shift 성공률 12~14% 는 T0 임계값과 이 표본에서의 값이다. v2.3 의 OD 분류 결과가 아니다.
- 혼잡은 외생 고정값이다. 한 사람이 경로를 바꾸는 상황만 평가한다.
- 판정이 뒤집힌 67건 중 실제 사례는 `reports/v2/td_engine_validation_detail.csv`
  (`rs_step != rs_v1`) 에서 확인하고, v2.1 에서 대표 사례 2~3개를 그림으로 만든다.
