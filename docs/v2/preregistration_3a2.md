# 사전 등록 — Phase 3A-2 코레일 1호선 경로 엔진 확장 (D-093)

- 고정일: 2026-11-22. **이 문서와 D-093 은 3A-2 의 어떤 경로 계산 결과보다 먼저 커밋한다.** 결과를 본 뒤 바꾸는 항목은 새 D 번호로 따로 기록한다.
- 근거: D-085(범위·정제), D-086(대기 급변 판정, 정책 초안 R1~R7), D-088(노량진·석계 3.0분), D-089(3-B 제외 구간), [3A-1 설계](../../reports/v2/line1k_3a1_report.md), [3A-1 검사 결과](../../reports/v2/line1k_3a1_build.md).
- 범위: 1호선 코레일 서울 26역 일반열차(급행은 3A-3). 3-B(경의중앙·수인분당·공항철도)는 포함하지 않는다.

## 1. 구로 1호선↔1호선 갈아타기

| 항목 | 내용 |
|---|---|
| 걷는 시간 | **1분** (환승 보행시간만). 근거: 사용자가 네이버지도·카카오지하철·공식 안내자료를 교차확인 (2026-11-22). 저장소 쪽에서는 원문을 따로 열어 보지 않았으므로 출처 표기는 '사용자 확인' |
| 대기 | 걷는 시간과 **별도**로, 갈아탈 열차의 목적지 필터 기대 대기 E (아래 R1) |
| 적용 조건 | 구로에서 **열차번호가 바뀔 때만**. 같은 열차번호로 구로를 지나 목적지 방면으로 계속 가면 갈아타기가 아니므로 걷는 시간·대기 0. 직통 여부는 시각표의 열차번호와 정차 순서(운행계통)로 판단 |
| 실제로 생기는 경우 | ① 경인(구일·개봉·오류동·온수) ↔ 경부 남쪽(가산디지털단지·독산·금천구청): 직통 열차 0 (테스트 고정). ② 구로 종착 열차 → 구로 시발 열차 (평일 구로 종착 36·시발 36편성): 같은 1분을 쓰되 근거는 ①을 넓힌 것이므로 '확장 적용'으로 표시 |
| 다른 역 | 같은 1호선 안 갈아타기는 **구로에서만** 둔다. 광운대·영등포·창동 등 다른 중간 종착역에서는 목적지까지 가는 열차를 기다리는 것으로 계산(목적지 필터) — 한계로 기록 |
| 민감도 | 구로 걷는 시간 **0·1·3·5분** (기본 1분) |

## 2. 대기시간 정책 (D-086 R1~R7 확정판)

| # | 확정 내용 |
|---|---|
| R1 | 코레일 구간에서 **타는 열차의 대기**는 목적지 필터 기대 대기 E(30분 구간, 아래 3절). 1~8호선·9호선은 기존 규칙(배차÷2, 최대 12분, D-044) 그대로 |
| R2 | 실시간 운행정보가 없으므로 화면 문구는 **'시각표상 다음 열차'**("시각표상 다음 열차까지 n분"). 시각표상 다음 열차 대기와 E 가 **5분 이상** 차이 나면 "평소보다 깁니다/짧습니다" 안내. 판정·점수에는 쓰지 않는다 |
| R3 | 목적지행 열차까지 **60분 초과**이면 추천 후보에서 제외. 사유를 **'운행 시작 전'(첫차 전) · '운행 종료'(막차 뒤) · '장시간 대기 제외'(다음 열차는 있으나 60분 초과)**로 나눠 표시. 운행 여부는 그 경로가 그 역에 **실제로 도착하는 분**에 시각표상 다음 열차가 60분 안에 있는지로 판단하고(존재 판정), 대기 값은 그 30분 구간의 E 를 쓴다 |
| R4 | 첫 승차 대기는 기존대로 넣지 않는다(D-003). 화면에 "첫 열차를 기다리는 시간은 소요시간에 넣지 않았습니다 (시각표상 다음 열차: n분 뒤)"처럼 **계산 범위를 명시** |
| R5 | E 에는 12분 상한을 두지 않는다. 비교용으로 'E 를 12분에서 자른' 시나리오를 따로 계산해 보고 |
| R6 | 30분 경계의 차이는 평활화하지 않는다. 대신 **시간 역전 검사**(4절 V3)를 하고 결과를 보고 |
| R7 | 코레일 대기를 E 와 H(그 역·방향 전체 열차 배차÷2)로 각각 계산해 **경로 순위·소요시간·환승 횟수·1순위 추천 변경**을 비교. **혼잡도 미확인 코레일 구간이 들어간 경로에는 v2.3 혼잡 회피 유형분류(시간 대안/경로 대안/대안 없음)를 적용하지 않는다** |

### R7 보충 — 혼잡 판정
- 코레일 구간을 하나라도 지나는 경로: 유형 = **'혼잡 판정 제외(코레일 구간 혼잡도 미확인)'**. 1~9호선 구간의 정원 100% 이상 노출은 '확인된 구간 기준 하한'으로만 표시.
- 코레일 구간을 지나지 않는 경로: 기존 v2.3 기준 그대로.
- 코레일 구간이 들어간 경로를 '쾌적 경로'로 확정 추천하지 않는다 (Phase 3 원칙).

## 3. E 계산 (검증 3 반영)

- E = 30분 구간 [s, s+30) 에 균등하게 도착한 승객이, 도착 뒤 처음 오는 **목적지(또는 다음 갈아탈 역)에 정차하는** 열차를 탈 때의 평균 대기. 구간 안 열차만이 아니라 **구간 끝 뒤 첫 열차까지** 써서 정확히 적분한다(`korail_line1.wait_profile`). 구간 전에 떠난 열차는 쓰지 않는다.
- 60분을 넘게 기다려야 하는 승객은 E 평균에서 빼고 R3 사유별 비율로 따로 기록.
- 구간 안 열차가 0·1대인 경우, 막차가 구간 가운데인 경우, 첫차 전인 경우를 단위 테스트로 고정.
- '목적지'는 최종 목적지가 아니라 그 열차에서 내릴 역(다음 갈아탈 역).

## 4. 3A-2 에서 만들 결과와 판정 기준

| # | 무엇 | 표본·방법 | 판정·보고 |
|---|---|---|---|
| V1 보존 | 기능 끔 | v2.3 3,720건, v2.6 B군, 앱 기준값 | 불일치 0 이어야 통과(아니면 3A-2 중단) |
| V2 변경 보고 | 기능 켬, 같은 v2.3 3,720건 | 기존 기준 경로와 간선 목록 비교 | 바뀐 건수·목록·원인 분류(코레일 구간 사용 / 구로 갈아타기 / 코레일 환승역 새로 생김 / 기타). 바뀐 건 중 코레일 구간을 지나는 것은 R7 보충대로 '혼잡 판정 제외'로 따로 셈. 기존 v2.3 결과 파일은 덮어쓰지 않음 |
| V3 시간 역전 | 기능 켬 | K 표본(아래) × 평일 07:00~09:00·17:30~19:30 1분 간격 출발 | 역전 = t1 < t2 인데 도착(t1) > 도착(t2) + 0.5분. OD 비율·최대 크기 보고. **모든 역전이 어떤 갈아탈 역에서 30분 경계를 넘는 것과 겹쳐야 정상**(아니면 버그로 보고 고침). 같은 방법으로 기존 1~9호선(배차÷2 구간값)의 역전도 재서 기준선으로 함께 보고 |
| V4 E vs H | 기능 켬 | K 표본 × v2.3 과 같은 평일 6개 출발 | 1순위 경로 변경률, 소요시간 차이 분포(중앙·90%), 환승 횟수 변화, 후보 5개 순위 변화(겹치는 후보의 순위 상관) |
| V5 구로 민감도 | 기능 켬 | 경인↔경부 남쪽 24개 방향쌍 + 지정 OD × 6개 출발 | 구로 0·1·3·5분별 1순위 경로·소요시간 변화 |
| V6 상한 | 기능 켬 | K 표본 × 6개 출발 | E 12분 상한 시나리오와 1순위·소요시간 비교 (R5) |
| V7 운행 없음 | 기능 켬 | K 표본, 평일 하루 전체 30분 구간 | 후보 제외 건수를 R3 사유 3가지로 나눠 보고 |

**K 표본** (코레일 표본): 한쪽 끝이 코레일 서울 26역이고 다른 쪽이 1~9호선 또는 코레일 역인 OD 중 **무작위 400쌍(시드 42)** + 지정 OD 12쌍.
지정 OD: 구일→가산디지털단지, 독산→개봉, 회기→가산디지털단지, 석계→독산, 외대앞→금천구청, 신이문→독산, 노량진→여의도, 석계→태릉입구, 용산→서울역, 남영→시청, 도봉산→창동, 온수→신도림.

## 5. 하지 않는 것

- 30분 경계 평활화(R6), 구로 외 같은 노선 갈아타기 추가(1절).
