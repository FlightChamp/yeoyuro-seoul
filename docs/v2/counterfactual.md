# Counterfactual card (v2 Release)

경로 검색 결과 아래에 "이 혼잡은 경로로 피할 수 있나, 시간으로 피할 수 있나"를 그 이동 하나에 대해 보여 준다.
v2.3 OD 분류를 개인 화면으로 옮긴 것이며, 판정 규칙은 분석과 같다.

| 칸 | 내용 | 규칙 |
|---|---|---|
| 지금 | 같은 시각의 시간 진행형 최속 경로 | v2.3 분류의 기준 경로와 동일 |
| 경로 변경 | 조건을 통과한 후보 중 100%+ 노출을 가장 많이 줄이는 경로 | T1: 노출 5분 이상 또는 50% 이상 감소, 소요 +15분·체감 +5분·환승 +1 이내, 경로 유사도 ≤ 0.65 |
| 시간 조정 | 조건을 통과한 시각 중 이동 폭이 가장 작은 시각 | T1: ±60분, 같은(또는 거의 같은) 경로, 소요 +5분 이내 |
| 경로 + 시간 함께 | 경로와 시각을 함께 바꾼 대안 (참고) | 강건성 검증 R2 joint 조건, 주 판정에는 쓰지 않음 (D-035) |

- 상단 판정(여유 / 경로로 / 시간으로 / 둘 다 / 구조적)은 `od_shiftability.classify()` 결과 그대로다.
- 대안이 기준에 못 미치면 "가장 가까운 후보"의 수치와 실패 이유(예: 소요시간이 15분 넘게 늘어남)를 함께 보여 준다.
- 코드: `yeoyuro_v2/counterfactual.py` (Streamlit 비의존), 앱: `render_counterfactual()`, 테스트: `tests/test_counterfactual.py`.

## 대표 사례 (평일, 앱 데이터 1~9호선)

| 이동 | 판정 | 요약 |
|---|---|---|
| 상봉→건대입구 08:00 | 구조적 | 경로 변경은 +30분 이상, 1시간 일찍 가도 노출 12→9분 (v2.3 7호선 회랑) |
| 가양→고속터미널 08:00 | 구조적 | 9호선 급행 회랑 (v2.6) |
| 신림→강남 08:15 | 시간으로 | 1시간 일찍 출발하면 노출 15→7분, 같은 경로 |
| 강변→여의도 08:30 | 둘 다 | 경로 변경·30분 늦게 출발 모두 노출 4→0분 |
| 노원→수유 08:00 | 여유 | 100%+ 노출 0분 |
