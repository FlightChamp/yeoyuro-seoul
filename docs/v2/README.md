# docs/v2 — 여유로 서울 제품 v2 문서

> **이름 주의**: `docs/PROJECT_PLAN_v2.md`, `docs/HANDOVER_v2.md`, `docs/HANDOVER_v3.md` 는
> **v1 개발 중의 기획 개정본·인수인계 기록**이다. 제품 v2 와 무관하며 소급 수정하지 않는다.
> 제품 v2 문서는 모두 이 폴더(`docs/v2/`)에 둔다.

## 규칙

1. 문서에 적는 수치는 `reports/v2/*.md` 산출물에서만 인용한다. 분석 전 수치는 쓰지 않는다.
2. 임계값·정책을 바꾸면 `decision_log.md` 에 날짜·이유와 함께 먼저 기록한다.
3. "실시간", "예측", "스트레스 지수" 표현을 쓰지 않는다. "과거 패턴 기반 기대 혼잡", "혼잡 노출 시간"을 쓴다.
