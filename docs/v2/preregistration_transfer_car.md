# 사전 등록 — 환승동선 인접 칸의 역 통과 전후 승하차 변화 (P1 보조분석)

- 등록: 2026-10-16 (분석 코드 실행 전에 커밋한다)
- 성격: 공모전 핵심 기능이 아닌 **보조분석**. 반나절 시간 제한(초과 시 중단하고 그 상태로 기록).
- 결과와 무관하게 `reports/v2/transfer_car_report.md` 에 그대로 기록한다.

## 1. 가설 (고정)

**주 가설:** 환승동선 인접 칸(빠른 환승 하차 칸 ±1)에서 역 통과 전후 혼잡 변화가 다른 칸보다 상대적으로 더 음수(하차 쪽)로 나타난다.

- 인과 주장을 하지 않는다 ("환승동선이 혼잡을 만든다"가 아니다).
- 검증 대상은 **환승동선**이다. 엘리베이터 등 넓은 의미의 시설 동선은 이 분석의 대상이 아니다. 엘리베이터 Facility PoC 와는 별개의 보조 근거로 둔다.

## 2. 데이터

- 칸별 혼잡도: 공모전 제공 4호선 샘플(편성 6개, 2026-06-17~28, 10초 간격). 원본에서 빈 칸이 있는 행은 제외(기존 검증과 같은 정의). 값은 원값(raw).
- 평일만. 시간대 제한 없음(05:30~익일 01:00 자료 전체).
- 환승 칸: `data/marts/transfer_tip_mart.parquet` (앱의 빠른 환승 안내 원천). `from_line = 4` 인 행의 `alight_car` = 4호선에서 내려 다른 노선으로 갈아탈 때 가까운 칸, `arrive_toward` = 4호선 열차의 진행 방면.
- 대상 역: 이 표에 4호선 하차 환승 정보가 있는 모든 역 (노원, 동대문, 동대문역사문화공원, 충무로, 서울역, 삼각지, 이수, 사당). 역명은 샘플 별칭(당고개→불암산, 총신대입구→이수)으로 맞춘다.
- 한 역·방향에 환승 노선이 여럿이면 하차 칸 ±1 의 **합집합**을 대상 칸으로 한다.

## 3. 단위와 지표 (pseudo-replication 방지)

1. **열차 통과** p = (편성, 날짜, 환승역 S, 이전역→S→다음역). S 도착 전 역간(이전역→S)과 S 출발 후 역간(S→다음역)이 시간상 연속(10분 이내)인 경우만.
2. 각 역간의 10초 행은 칸별 **중앙값** 하나로 압축한다. 10초 행은 독립 표본으로 쓰지 않는다.
3. Δ_{p,c} = 출발 후 중앙값 − 도착 전 중앙값 (칸 c = 1..10).
4. 중심화: Δc_{p,c} = Δ_{p,c} − mean_c(Δ_{p,c}) (열차 전체 승하차량의 영향 제거).
5. 통과별 효과: e_p = mean(Δc, 대상 칸) − mean(Δc, 나머지 칸). **하차 집중이면 e_p < 0.**

## 4. 칸 번호 기준 (분석 전 고정)

- **Primary:** 진행 방향 기준 — 샘플의 c번째 칸 = 빠른 환승의 c번째 칸.
- **Mirror (대조):** 반전 기준 — 샘플의 c번째 칸 = 빠른 환승의 (11 − c)번째 칸.
- 어느 쪽에서 효과가 나와도 칸 번호의 공식 정의를 확정하지 않는다. 표현은 "진행 방향 기준 해석에서 결과가 더 일관적이었다"까지.

## 5. 통계

- Pooled effect = 모든 통과의 e_p 평균.
- 95% 신뢰구간: **날짜 → 열차 통과** 2단계 hierarchical bootstrap (날짜를 복원추출한 뒤, 뽑힌 각 날짜 안에서 통과를 복원추출), B = 2000, seed = 20261016.
- 역×방향 조합: 통과 5회 이상인 조합만 센다. 각 조합의 평균 e 부호를 본다.

## 6. 판정 (고정)

"환승동선 인접 칸에서 역 통과 전후 승하차 변화가 집중되는 경향" 으로 보고하는 조건 — **둘 다** 만족:

1. Primary 의 pooled effect 95% CI 상한 < 0
2. Primary 에서 집계 대상 역×방향 조합의 절반 이상이 음수

보조 조건 (보고만, 판정을 뒤집지 않음): Mirror 에서는 위 두 조건을 함께 만족하지 않는다.

- 통과 → 기획서에 한 문장만 추가 (연관 표현, 인과 금지, 표본 범위 명시).
- 실패 → 기획서에 추가하지 않는다. 기존 엘리베이터 Facility PoC 유지. 결과는 내부 보고서에만 기록.

## 7. 탐색 분석 (판정에 쓰지 않음)

- 승차 칸(`board_car`) ±1 의 e_p (승차 집중이면 > 0). 빠른 환승 표의 승차 칸이 여러 역에서 진행 방향과 무관하게 같은 값이라 데이터 품질 문제로 primary 에서 제외.
- 피크(07:00~09:00, 18:00~19:30) 한정 pooled effect.

## 8. 사전 공개 사항

- 2026-10-15, 칸 번호 기준을 확인하려고 4호선 모든 역의 계단·에스컬레이터·엘리베이터 인접 칸 |Δ| 를 비교하는 탐색을 한 번 했다 (판정 없음, 차이 약 0.5%p, 결론 없음). 이 분석은 그와 다른 대상(환승 하차 칸)·지표(부호 있는 중심화 Δ)를 쓴다.
