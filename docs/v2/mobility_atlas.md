# Mobility Atlas (혼잡 분산 지도)

v2.4 결론: **혼잡 노출이 큰 구간과 구조적 혼잡이 몰린 구간은 서로 다르다.** 노출 합계 상위는 7호선 중랑·광진 구간,
8호선 석촌→송파, 2호선 낙성대→사당 등이지만, 그 구간에서 100%+ 를 겪은 이동이 경로·시간 조정 모두로 피하기 어려운
비율(구조적 혼잡 비율)은 **7호선 상봉→건대입구 회랑(22~30%)** 에서만 두드러진다. 지표 간 순위 상관이 낮아
(노출 vs 경로 대안 0.12, 노출 vs 구조적 비율 0.24) 하나의 점수로 합치지 않는 근거가 된다.
수치 출처: [`reports/v2/mobility_atlas_report.md`](../../reports/v2/mobility_atlas_report.md).

## 1. 왜 단일 Stress Index 를 만들지 않는가

- 피로·스트레스의 정답 데이터(설문, 생체 신호 등)가 없다. `0.4×혼잡 + 0.3×환승 + …` 의 가중치를 정당화할 방법이 없다.
- 실측에서도 지표들이 서로 다른 구간을 가리킨다 (§3 상관표). 합치면 그 차이가 사라진다.
- 단일 점수는 v3 과제로 둔다: 사용자 설문으로 지표별 체감 가중치를 학습·보정할 수 있을 때.

## 2. 지표 정의 (구간 = 역→역, 방향 있음)

| 지표 | 정의 | 방향 |
|---|---|---|
| congestion_exposure | 표본 이동이 이 구간을 지날 때의 100%+ 노출(분) 평균 | 높을수록 나쁨 |
| demand_weighted_exposure | 위 값을 수요 proxy 로 가중 | 높을수록 나쁨 |
| exposed_traversal_share | 통과 중 이 구간에서 100%+ 를 겪은 비율 | 높을수록 나쁨 |
| structural_share | 이 구간에서 100%+ 를 겪은 이동 중 Structurally constrained 비율 | 높을수록 나쁨 |
| alternative_opportunity | 같은 분모 중 Route 성공(Route-shiftable + Dual) 비율 | 높을수록 좋음 |
| temporal_shift_benefit | 같은 분모 중 Time 성공(Time-shiftable + Dual) 비율 | 높을수록 좋음 |

- 분모 "혼잡 통과"는 **그 구간에서 실제로 100%+ 를 겪은 통과**다. 이동 전체의 판정을 혼잡을 겪지 않은 구간에까지
  칠하면, 구조적 이동의 출발 구간(예: 5호선 마천 방면)이 구조적으로 보이는 왜곡이 생긴다 (D-025, 초안에서 실제 확인).
- 비율 지표는 혼잡 통과가 5건 미만이면 비운다.
- transfer_burden(환승 부담)은 v2.3 evidence 가 환승역별 대기·도보를 저장하지 않아 이번 단계에서 제외했다 (D-024).
  event_sensitivity 는 v2.5 에서 붙인다.

## 3. 결과 요약 (평일, 오전·오후 합산)

| 관점 | 상위 구간 |
|---|---|
| 노출 합계 | 7호선 중곡→군자, 7호선 용마산→중곡, 8호선 석촌→송파, 7호선 사가정→용마산, 7호선 면목→사가정 |
| 구조적 혼잡 비율 (노출 합계 30분 이상) | 7호선 상봉→면목 30%, 어린이대공원→건대입구 26%, 군자→어린이대공원 25%, 중곡→군자 23% |
| 경로 대안 0% | 5호선 목동→오목교, 6호선 창신→동묘앞, 보문→창신, 5호선 여의도→여의나루 (모두 시간 조정으로는 해결) |
| 노선별 노출 비중 | 7호선 26.9%, 2호선 24.2%, 3·5호선 각 12.3% |

지표 간 순위 상관 (Spearman, 혼잡 통과 ≥5 구간): 노출–구조적 0.24, 노출–경로 대안 0.12, 노출–시간 조정 −0.30.
structural_share 와 temporal_shift_benefit 의 −0.86 은 정의상 겹치기 때문이며 발견이 아니다.

## 4. 앱 화면 ('혼잡 분산 지도' 메뉴)

- 시간대(오전/오후/전체) × 지표 선택 → v1 벡터 노선도 위에 구간 색칠 (양방향 중 나쁜 쪽 값, 5단계).
- 유형 분포 카드: 역 쌍 수 기준 / 수요 proxy 기준 전환.
- 상위 10구간 표와 "읽는 법" (종합 점수 없음, 창 민감도, proxy 한계).

## 5. 한계

- 무작위 OD 620쌍의 기준 경로 집계다. 표본에 덜 잡힌 구간은 값이 비거나 불안정하다.
- 구간 값은 "그 구간 승객 전체"가 아니라 "그 구간을 지나는 표본 이동"의 값이다.
- 구조적 혼잡 비율의 크기는 Time 창(±60분)에 민감하다 (od_shiftability.md §4).
