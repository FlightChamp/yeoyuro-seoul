## 0. 먼저 밝혀 둘 가정 — 이벤트 혼잡은 측정값이 아니라 시나리오다

혼잡도 원자료는 분기 스냅샷 평균이라 **이벤트 당일의 차내 혼잡은 관측되지 않는다.**
v1 은 이벤트 당일 승하차 급증(spike_ratio, 실측)을 차내 혼잡 배수로 바꾸는 가정을 썼다.

```
혼잡 배수 m = 1 + w × (spike_ratio − 1) × λ        (λ = 0.3, w = 검증 강도 가중치)
```

- 배수는 이벤트 역(anchor + impact)에서 **출발하는 구간**, 이벤트 시간대에만 곱한다 (v1 규칙 그대로).
- λ 는 관측으로 보정된 값이 아니다. 따라서 v2.5 의 결론은 "이 가정 아래에서"로만 말하고, λ = 0.15 / 0.3 / 0.6 결과를 함께 보고한다.
- 판정(H4)은 v1 값인 λ = 0.3 에서만 한다.

## 2. 표본 (이벤트마다)

| 구분 | 구성 |

## 3. 영향 여부 정의

단위가 **직접 영향(treated)** 이려면, 평시 기준 경로 또는 이벤트 기준 경로 중 하나라도
배수 > 1 인 구간을 지나야 한다 (이벤트 시나리오에서 구간 진입 시각 기준으로 판정).
그 외는 **간접(untreated)** 이다. 간접 단위의 유형이 바뀌는 경로는 "대안 경로가 이벤트 역을 지나 대안이 사라지는 경우"뿐이다.

## 4. 가설과 반증 조건 (λ = 0.3)

분석 모집단 = 4개 이벤트 통합, 직접 영향 단위 중 **평시에 혼잡 이동(Calm 아님)** 이었던 단위.
불확실성 = OD 단위 cluster bootstrap 1,000회 95% 구간.

| ID | 가설 | 측정 | 반증 조건 |
|---|---|---|---|
| H4a | 이벤트는 시간 조정의 효과를 약화시킨다 | Time 성공률 (이벤트 − 평시) | 감소폭 < 5%p 이거나 95% 구간 상한 ≥ 0 |
| H4b | 이벤트는 구조적 혼잡을 늘린다 | Structural 비율 (이벤트 − 평시) | 증가폭 < 2%p 이거나 95% 구간 하한 ≤ 0 |

판정 불가: 위 모집단이 30단위 미만이면 H4a·H4b 를 판정하지 않고 "판정 불가"로 보고한다.

탐색적 보고 (반증 조건 없음):
- 이벤트별 평시 → 이벤트 유형 전이 행렬 (직접 영향 단위 전체, Calm 포함)
- 평시 Calm 이었다가 이벤트에서 혼잡해진 단위의 유형 분포
- 간접 단위의 유형 변화율 (대안 상실 파급)
- λ = 0.15 / 0.6 에서의 H4a·H4b 측정값

## 5. 보고 원칙

- 반증·판정 불가는 그대로 보고한다. 이벤트·시각·λ 를 바꿔 다시 돌리지 않는다.
- "이벤트 날 실제로 X% 가 구조적 혼잡이었다"는 표현 금지. "v1 이벤트 배수 가정(λ=0.3) 아래 시나리오에서"로 쓴다.
