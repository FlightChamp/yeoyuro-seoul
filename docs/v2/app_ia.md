# 앱 정보 구조 (IA) 리팩토링 — Release

계산·라우팅·mart 로직은 바꾸지 않았다. 화면 배치, 페이지 이동, 공유 입력 상태만 바꿨다 (D-057).

## 사이드바 (1차 메뉴 4개)

| 메뉴 | subview | 예전 메뉴 |
|---|---|---|
| 경로 추천 | 경로 / 시간 바꿔 보기 | 쾌적 경로 찾기, 시간 분산, 빠른 환승 안내(→ 경로 결과 안으로) |
| 혼잡 탐색 | 역·노선별 / 네트워크 지도 | 시간대별 혼잡 조회, 혼잡 분산 지도 |
| 이벤트 분석 | 시나리오 / 과거 데이터 | 이벤트 시나리오, 이벤트 혼잡 경보 |
| 프로젝트 & 검증 | 탭: 개요 / 데이터 / 방법론 / 검증 결과 / 한계 | 프로젝트 소개 및 검증 리포트 |

- subview 는 `st.tabs` 대신 `st.segmented_control(required=True)` + `session_state` (`view_route`, `view_explore`, `view_event`).
  `st.tabs` 는 모든 탭을 매번 실행하고 코드로 특정 탭을 열 수 없어 CTA 이동에 쓸 수 없다.
- 예전 메뉴 이름(`session_state["menu"]`)은 `LEGACY_MENU` 로 새 위치에 옮긴다 (이전 세션·테스트 호환).
- 노선도 편집은 그대로 `?edit=1` 일 때만 보인다.

## 공유 입력 (one input, multiple views)

- source of truth = 일반 key `origin_station_key`, `destination_station_key`, `q_date`, `q_time`, `q_mode`.
- 위젯 → canonical: 각 위젯의 `on_change`. canonical → 위젯: 페이지·subview 이동 콜백(`_go`, segmented_control `on_change`)에서만
  `_sync_widgets_from_canonical()`, 그리고 위젯 state 가 없을 때의 `_seed()`. 매 렌더마다 덮어쓰지 않는다.
- 경로 결과는 계산할 때의 입력 서명 `route_query = (출발, 도착, 날짜, 시각, 모드)` 와 함께 저장한다.
  지금 입력과 다르면 결과·노선도 하이라이트·CTA 를 숨기고 "다시 검색" 안내만 보인다 (stale).

## 경로 → 시간 바꿔 보기 CTA

- 조건: Counterfactual 의 `time.ok` (v2.3 사전 등록 기준 T1 판정) — 임의의 혼잡도 임계값을 쓰지 않는다.
- 문구: "30분 늦게(08:45) 출발하면 100%+ 혼잡 노출이 7분 줄어듭니다 (12분 → 5분)." + [시간 비교 보기 →]
- 클릭하면 `ts_handoff = {sig, path(=Counterfactual 기준 최속 경로), shift_min}` 를 넘긴다.
- 시간 바꿔 보기는 `ts_handoff.sig == 지금 입력 == route_query` 이고 path 가 있을 때만 자동 계산한다.
  같은 엔진(TDRouter)·같은 기준 path·같은 T1 이라 1순위 시각이 CTA 시각과 같다 (테스트로 고정).
- 직접 들어왔거나 조건이 바뀌었으면 입력부 + [비교하기] (기존 계산 방식 그대로).

## 용어·안내

- 사용자 화면의 `structural` = **회피 어려움**. 정의(tooltip): "정해진 경로·시간 대안 범위에서 개선안이 발견되지 않은 이동".
  카드 문구: "현재 탐색한 경로·시간 대안 범위에서는 뚜렷한 개선안을 찾지 못했습니다." 내부 타입명·mart 값은 그대로.
- 큰 '실시간 아님' 안내 박스를 없애고, 사이드바 하단 + 경로/시간 결과 아래에 작은 한 줄
  "ⓘ 과거 패턴 기반 기대값 · 실시간 정보 아님" (tooltip 에 상세 정의). 이벤트 시나리오의 가정 경고는 유지.
- 이벤트: '이벤트 혼잡 경보' 표현을 쓰지 않는다 (실시간 알림으로 오해). 과거 데이터 = 시나리오 가정의 근거, 시나리오 = what-if,
  두 화면에 서로 가는 버튼.

## 환승 안내

경로 결과의 각 환승 구간 바로 아래: "↓ 석촌 · 8호선 → 9호선 / 🚶 빠른 하차 … · 예상 환승 약 N분 (도보·대기)" +
[자세히 보기] (방면별 하차·승차 위치 표, 환승 소요·평일 환승인원·환승 페널티). 자료가 없으면 "빠른 환승 위치 정보 미제공".
