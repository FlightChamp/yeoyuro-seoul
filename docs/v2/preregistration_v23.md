## 4. 가설과 반증 조건 (고정)

"혼잡 이동" = Calm 이 아닌 단위. 비율은 모두 OD-count 기준이 주 결과이며, 수요 proxy 가중은 병기한다.

| ID | 가설 | 측정 | 반증 조건 |
|---|---|---|---|
| H1 | 경로 변경은 일부 혼잡 이동에만 효과가 있다 | 혼잡 이동 중 Route 성공(Route-shiftable + Dual) 비율 | < 1% 또는 > 50% |
| H2 | 경로로 못 피하는 이동 중 상당수는 시간으로 피할 수 있다 | Route 실패 혼잡 이동 중 Time 성공 비율 | < 5% |
| H3 | 구조적 혼잡은 특정 구간에 집중된다 | Structural 이동의 100%+ 노출(분)을 구간(edge)별로 합산했을 때 상위 10개 구간 비중 | 혼잡 이동 안에서 Structural 라벨을 무작위로 섞은 1,000회 순열 대비 p ≥ 0.05 |
| H5 | 분류는 임계값 선택의 인공물이 아니다 | 아래 단일 요인 변경 각각에서 유형 유지율 (분모 = T1 에서 혼잡 이동인 단위, 같은 유형으로 남는 비율) | 하나라도 < 70% 이면 그 요인을 결론에 명시. 절반 이상이 < 70% 이면 결론을 "탐색적"으로 격하 |

H4(이벤트 전이)는 v2.5 에서 별도 등록한다.

불확실성: 유형 비율은 OD 단위 cluster bootstrap 1,000회 95% 구간을 함께 보고한다.

## 5. 수요 proxy (가중 결과용)

```
w(o,d,t) = B_o(h_t) × A_d(h_arr) / Σ_k A_k(h_arr)
```

- B_o: 출발역 평일 일평균 승차, A_d: 도착역 평일 일평균 하차 (2025-07~2026-06, `demand_station_hour.parquet`)
- h_t: 출발 시각의 시(hour), h_arr: 기준 경로 도착 시각의 시
- 거리 감쇠 없음 → 원거리 OD 과대 가능. 대안 proxy: × exp(−β·소요분), β = 0.03, 0.06 (sensitivity)
- 공휴일을 평일에서 제외하지 않았다 (캘린더 없음).
- 표현 규칙: "실제 승객 이동량의 N%" 금지. "승하차 기반 수요 proxy 가중 N%" 로 쓴다.

## 7. 보고 원칙

- 반증 조건에 걸리면 그대로 보고한다. 기준을 바꿔 다시 돌리지 않는다.
- 표본은 무작위 OD 이므로, OD-count 비율은 "역 쌍 기준"이지 "이동량 기준"이 아니다.
- Route-shiftable 은 "한 사람이 옮길 때" 기준이다. 수요 재배분은 반영하지 않는다 (기획서 R1).
