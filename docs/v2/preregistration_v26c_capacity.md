# v2.6c 사전 등록 — 9호선 정원 기준 보정 검사

> Phase B 결과(Structural 상위 10구간이 모두 9호선 급행)를 **본 뒤에** 떠올린 검사다 (D-053).
> 그래서 판정 기준을 이 문서로 먼저 고정하고 커밋한 뒤 실행한다.

- 등록일: 2026-10-05 · 분류 기준 `T1_prereg_v23` · Phase B 기본값(최초 대기 미포함, 환승 ×1.81) 그대로

## 문제

혼잡도 100% 의 정원 인원이 노선마다 다르다. 1~8호선 1칸 160명, 9호선 6칸 922명(1칸 약 153.7명).
같은 칸당 인원이면 9호선 % 가 약 4% 높게 나온다. 9호선 급행이 "가장 구조적"으로 나온 것이 이 차이 때문인지 확인한다.

## 방법

- 시나리오 `cap160`: 9호선 혼잡도(중앙값)에 (922/6)/160 = 0.9604 를 곱해 1~8호선 정원 기준으로 환산. 나머지는 Phase B base 와 동일
- 표본: Phase B 와 같은 A+B 600쌍 × 평일 6개 시각 (seed 2027)
- 비교 대상: Phase B base (이미 계산된 evidence 재사용)
