## 3-B 설계 전에 정할 것 (감사에서 드러난 것)

1. **토요일**: 세 노선 모두 평일·휴일 두 종류뿐. 토요일 = 휴일 시각표로 볼지 (참고: 3-A 1호선 코레일 열차는 서울교통공사 시각표에서 토·일 98.6% 동일 — 같다는 증거는 아님, 미확인).
2. **경춘선 열차**: 청량리–회기–중랑–상봉–망우는 경춘선 열차도 선다 (범위 안 두 역 이상: 평일 60/61대, 대부분 상봉 시발). 같은 승강장·같은 선로인지 확인 후 포함 여부.
3. **공항철도 최신 시각표**: 2026-10-23 개정 반영본을 받아야 함. 지금 파일은 설계·테스트용으로만.
4. **환승 보행시간**: 이 파일들에는 없음. 노선도의 3-B 환승 연결 25개에 대해 별도 근거 필요 (3-A 때처럼 공식 자료 → 사용자 교차 확인).
5. **같은 역번호, 다른 노선**: 용산 1003 = 1호선·경의중앙, 왕십리 1013 = 경의중앙·수인분당. 노드는 노선별로 따로 둬야 함.
6. **원본 파일 보관**: 코레일·공항철도 게시 자료를 저장소 data/raw 에 넣을지 (공개 가능 여부·이용 조건 미확인) 또는 mart 만 넣을지.
