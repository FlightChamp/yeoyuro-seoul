# Event Stress Test (이벤트 시나리오)

v2.5 결론: **사전 등록한 두 가설(H4a·H4b)은 모두 반증됐다.** 평시에 이미 혼잡하던 이동은 이벤트 시나리오에서도
대응 방법이 거의 바뀌지 않았다 (Time 성공률 97.7% → 97.7%, Structural 0% → 0%, 43단위).
대신 이벤트의 효과는 **평시에 여유롭던 이동을 새로 혼잡하게 만드는 쪽**으로 나타났다 (303단위, 그중 70단위 구조적).
이 부분은 사전 등록에서 "탐색적 보고"로 지정한 항목이며, 가설 검정 결과가 아니다.

### 왜 반증됐나 — 사전 등록 설계의 한계

불꽃축제(토 저녁)·제야의 종(밤)·핼러윈(금 밤)은 **평시 기준으로 혼잡하지 않은 시간대**다.
그래서 "평시 혼잡 이동"으로 정의한 판정 모집단에 이 이벤트들의 단위가 거의 들어오지 않았고 (불꽃 0, 제야 0, 핼러윈 2),
가설은 사실상 벚꽃 한 이벤트로 검정됐다. 모집단 정의가 현상의 주된 부분을 비켜 갔다는 것이 이번 반증의 가장 중요한 교훈이다.
가설을 고쳐 다시 검정하지 않았다 (사전 등록 §5). 고친 가설은 다음 사전 등록의 후보로만 기록한다 (D-030).

### Structural 70단위를 읽는 법 (중요)

- 70단위 중 54단위가 **이벤트 방문 이동**(anchor 역으로 가거나 나오는 이동)이다. 목적지 자체가 혼잡하므로 경로로 피할 수 없다.
- 시간 조정이 실패한 이유는 전부 "노출 감소 부족"이다. 불꽃축제는 v1 규칙상 배수가 **종일** 적용되고(apply_scope=daily),
  제야의 종은 20~01시 적용이라 기준 시각 ±60분이 모두 이벤트 시간 안에 들어간다.
- 즉 이벤트의 Structural 은 상당 부분 **배수 적용 범위 가정의 결과**다. "이벤트 방문 이동은 ±60분 조정으로 피하기 어렵다"는
  직관과 맞지만, 그 크기를 결론으로 쓰지 않는다.
